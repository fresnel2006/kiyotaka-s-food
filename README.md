## 📱 À propos

**Kiyotaka's Food** est une application mobile multiplateforme destinée aux étudiants de mon école. Elle leur permet de consulter le menu disponible et de passer des commandes de nourriture directement depuis leur téléphone, sans file d'attente.

> L'interface d'administration (gestion des commandes, menu, etc.) est gérée via une application séparée.

---

## ✨ Fonctionnalités

- 🗂 **Parcourir le menu** — Consulter les plats disponibles avec leurs détails
- 🛒 **Passer une commande** — Sélectionner des articles et valider sa commande en quelques clics
- 🔐 **Authentification** — Connexion sécurisée via Supabase Auth

## 🚀 Installation

### Prérequis

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installé
- Un compte [Supabase](https://supabase.com) avec un projet configuré
- Android Studio ou VS Code avec l'extension Flutter

### Étapes

```bash
# 1. Cloner le dépôt
git clone https://github.com/fresnel2006/kiyotakas-food.git
cd kiyotakas-food

# 2. Installer les dépendances
flutter pub get

# 3. Configurer les variables d'environnement
# Crée un fichier lib/config/supabase_config.dart avec :
# const supabaseUrl = 'VOTRE_URL';
# const supabaseAnonKey = 'VOTRE_ANON_KEY';

# 4. Lancer l'application
flutter run
```
